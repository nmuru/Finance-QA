## Skill 5: Synthesis & Formatting (`skill_synthesis`)
**Objective:** Construct the final Markdown output.
**Instructions:**
1.  Do not include raw JSON structures in the output.
2.  Present quantitative data in Markdown tables (e.g., Columns: Metric, FY21, FY22, FY23).
3.  Format percentages to one decimal place (e.g., `15.4%`).
4.  Group findings strictly under the headers defined in the Agent Output Specifications.
